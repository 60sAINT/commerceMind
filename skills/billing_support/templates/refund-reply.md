# 账单问题回复模板

## 一、信息不足时

```text
我先帮你确认这个问题。请提供以下信息：
1. 订单号或交易号；
2. 支付时间；
3. 支付渠道；
4. 你希望处理的是退款、重复扣款、发票还是订阅问题。

拿到这些信息后，我才能继续判断退款条件或到账情况。
```

## 二、退款到账咨询

```text
退款通过后通常按原支付渠道退回，但不同渠道到账时间不同：
- 微信支付通常 1～5 个工作日；
- 支付宝通常 1～3 个工作日；
- 银行卡通常 3～7 个工作日；
- 平台余额通常较快，以余额记录为准。

如果页面显示退款成功但账户还没到账，建议先检查原支付账户和渠道账单。
超过常规时间仍未到账时，我可以帮你转人工核实退款流水号。
```

## 三、重复扣款

```text
我需要先核实两笔扣款是否对应同一个订单。请提供：
1. 两笔交易的时间和金额；
2. 支付渠道；
3. 订单号或交易号；
4. 两笔交易的账单截图摘要（不需要完整银行卡号）。

如果确认是重复扣款，通常需要人工或财务核验后处理，我不能直接承诺自动退回。
```

## 四、发票问题

```text
发票问题需要先确认：
1. 个人发票还是企业发票；
2. 普通发票还是专用发票；
3. 抬头、税号、邮箱；
4. 开票金额和订单范围；
5. 是否需要作废或重开。

跨月、已报销或需要修改抬头的发票通常需要人工审核。
```

## 五、禁止使用的表达

```text
禁止：
- “肯定能退”；
- “马上到账”；
- “已经退款”；
- “扣款一定正常”；
- “把银行卡号和支付密码发给我”。
```
