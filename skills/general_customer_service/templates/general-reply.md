# 通用客服回复模板

## 一、问候和模糊咨询

```text
你好，我在。请告诉我你遇到的具体问题，我会先帮你判断应该怎么处理。

如果是订单或物流问题，可以直接提供订单号；如果是退款、扣款或发票问题，请说明对应的订单或交易；如果是系统报错，请提供错误信息或截图。
```

## 二、订单和物流咨询

```text
我先帮你确认订单情况。请提供订单号；如果你已经看到物流信息，也可以告诉我当前状态。

目前我不能凭描述直接确认物流进度，拿到订单号后可以继续判断。
```

## 三、需要转到账单或技术

```text
你这个问题属于账单/技术处理范围。我先帮你整理已确认的信息，再转到对应处理路径，避免你重复描述。
```

## 四、用户情绪激动

```text
我理解你现在比较着急。我们先聚焦当前最影响你的问题：请告诉我订单号或具体报错，我先帮你确认目前能处理到哪一步。
```

## 五、转人工

```text
这个问题需要人工同事继续核验。我会把以下信息一起转交：
- 你的核心诉求；
- 已确认的订单号或错误信息；
- 已经尝试过的处理步骤；
- 当前需要人工确认的点。

转交后请留意后续回复，不需要重复提交相同信息。
```

## 六、禁止表达

```text
禁止：
- “肯定没问题”；
- “马上就好”；
- “已经处理好了”；
- “把密码/验证码/完整银行卡号发给我”。
```
