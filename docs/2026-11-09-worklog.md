## 怎么用 Docker 启动 Redis 和 ChromaDB

只需要 Docker Desktop，不需要单独安装 Redis 或 ChromaDB；第一次启动时 Docker 会自动拉取镜像。

```bash
cd /Users/lixinyi/Desktop/commerceMind
docker compose up -d redis chromadb
docker compose ps
```

端口和地址：

- app：`127.0.0.1:8000`
- Redis：`127.0.0.1:6379`
- ChromaDB：`127.0.0.1:8001`（容器内是 8000，映射到宿主机 8001，避免和 app 冲突）

如果 app 也在容器里，`.env` 使用 Compose 服务名：

```dotenv
REDIS_URL=redis://:commercemind123@redis:6379/0
CHROMA_HOST=chromadb
CHROMA_PORT=8000
```

如果 app 在本机用 `uvicorn` 启动，`.env` 改成宿主机地址：

```dotenv
REDIS_URL=redis://:commercemind123@localhost:6379/0
CHROMA_HOST=localhost
CHROMA_PORT=8001
```

启动全部服务：

```bash
docker compose up -d --build
```

## 怎么验证 Redis 和 ChromaDB 已经启动

```bash
# 两个服务都应该是 Up (healthy)
docker compose ps

# Redis：返回 PONG
docker compose exec redis sh -c 'redis-cli -a "$REDIS_PASSWORD" ping'

# ChromaDB：返回 nanosecond heartbeat
curl -sS http://127.0.0.1:8001/api/v1/heartbeat

# app：返回 status ok
curl -sS http://127.0.0.1:8000/health
```

启动失败时看日志：

```bash
docker compose logs --tail=50 redis chromadb
```

停止和清理：

```bash
docker compose stop      # 停止容器，保留数据
docker compose down      # 停止并删除容器，保留 Redis/Chroma 数据卷
docker compose down -v   # 连同数据卷一起删除（会清空数据）
```

## 备注

如果本地 Python 脚本在 `TokenCounter()` 处一直卡住，检查 `memory/tokenizer/deepseek-v4/tokenizer.json` 是否被 iCloud 变成了占位文件：

```bash
ls -lO memory/tokenizer/deepseek-v4/tokenizer.json
brctl download memory/tokenizer/deepseek-v4/tokenizer.json
```

带 `dataless` 标记时读取会等待 iCloud 下载；下载完成后脚本即可正常运行。

同样的问题也会出现在 `.venv`、`.git` 上，表现为 `pytest`、`git diff` 卡住不动。长期建议把项目移出 iCloud 同步目录，或关闭“优化 Mac 存储”。
