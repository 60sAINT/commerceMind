## 第一件事：7.1 知识库基础配置与 Chroma 生命周期

新增独立的 `KnowledgeBaseSettings`，可配置知识库启用状态、必需状态、Chroma 地址和 collection 名称；默认关闭，collection 名称经过格式校验。应用 `Settings.from_env()` 读取 `COMMERCEMIND_KNOWLEDGE_ENABLED`、`COMMERCEMIND_KNOWLEDGE_REQUIRED`、`COMMERCEMIND_KNOWLEDGE_COLLECTION`，Chroma 地址复用 `CHROMA_HOST` / `CHROMA_PORT`。

新增 `tooling/knowledge_base.py` 作为知识库 Chroma collection 的连接与生命周期入口。它只使用显式 HTTP 客户端，独立创建/获取 `knowledge_base` collection，不与记忆 collection 混用；构造时执行 heartbeat，连接或初始化失败会抛出带上下文的异常，不静默回退到本地空库。客户端支持显式关闭时由 `close()` 负责释放。

## 第二件事：7.2 文档切片与幂等导入

为知识库增加可配置的切片长度、重叠长度和 Chroma 写入批次上限。切片先规范化换行与水平空白，再按段落/中英文句末标点优先组合；超长无标点文本按字符边界切分，片段间按配置保留重叠，单片不会超过切片上限。

`add_documents()` 校验标题、正文和可选文档 ID。显式 ID 用作稳定文档身份；未提供时以标题作为身份。内容版本使用 SHA-256，片段 ID 按文档身份和片段序号稳定生成，元数据记录标题、文档 ID、版本、片段序号/总数及导入时间。导入按批 upsert，再删除该文档不再使用的旧片段；同批相同身份采用最后一个版本，因此重复导入幂等，同标题文档可通过不同显式 ID 共存。提供异步线程适配入口。

新增退款与配送主题的 CommerceMind 演示 JSON 文档，并明确标注其仅用于导入演示、不构成真实商家政策。增加切片、版本、同标题、旧片段清理、批次写入和输入校验测试。`git diff --check` 通过；环境仍缺少可用 Python/pytest 运行时，测试尚未执行。本次未提交。

## 第三件事：7.3 知识库检索与文档管理操作

新增 `search()` / `search_async()`，按 collection 默认 embedding 执行语义检索，校验非空 query 与 1–20 的 top-k，空库直接返回空列表。结果包含标题、片段正文、相似度分数、文档 ID、内容版本及片段序号/总数。

新增分页 `list_documents()`、`get_document()`、`delete_document()` 和 `stats()`，并提供对应异步线程适配方法。列表和统计按文档身份聚合，详情按片段序号排序；统计分别返回文档数与片段数。删除只匹配目标 `document_id` 下的片段，不存在时返回 `False`。添加检索、空库、分页校验、详情/删除和计数测试。`git diff --check` 通过；因当前环境缺少可用 Python/pytest 运行时，测试尚未执行。本次未提交。

## 第四件事：7.4 知识库管理 API

在 FastAPI 应用中加入知识库服务注入与生命周期管理。显式注入的服务归调用方所有；应用自行创建的客户端在关闭时释放。知识库启用且 required 时依赖初始化失败会阻止启动；required=false 时应用继续启动，管理接口对未启用、未初始化或请求期间依赖故障统一返回安全的 503 `knowledge_unavailable`。

新增 `GET /knowledge/stats`、分页 `GET /knowledge/documents`、`POST /knowledge/documents` 批量导入、`GET/DELETE /knowledge/documents/{document_id}` 和 `POST /knowledge/search`。请求模型校验标题/正文、ID、query、top-k、分页、文档数和批量总字符数；缺失文档返回 404，输入结构无效返回框架 422。依赖异常只记服务端日志，响应不包含 Chroma 错误正文或主机路径。新增 API 替身测试覆盖导入到删除闭环、校验、不可用降级、启动 required 行为和 OpenAPI 路由。
